To make it real

  1. Load access points with useAccessPoints(slug). Use riverMile for placement, and leave points with isFloatEndpoint === false unselectable, as the map does.
  2. Take the time from /api/plan, not from this page's math, so it uses the flow model and matches the planner. Keep the band model only as the what-if layer.
  3. Start the water level from the river's live condition. Treat the what-if control as a separate, clearly labeled mode.
  4. Respect floatTimeWithholding: dangerous returns no time, and dam-tailwater rivers return "regulated", which needs its own wording.
  5. Link the CTA with real IDs: /plan?river=…&putIn=…&takeOut=….
  6. Decide where it lives: a hero on the home page in place of the select-only form, or a "float this stretch" view on river pages.

Mile markers come from supabase/seed/*_miles.sql. The river's curves are drawn for illustration, not traced from its real geometry.
